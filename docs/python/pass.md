在 Python 中，`pass` 是一个空语句，占位符，表示什么也不做。它通常用于需要一个语法上必须有代码的位置，但暂时还没有实际实现时。

#### 1. **基本语法**

`pass` 不执行任何操作，直接跳过。例如：

> if True:  
>     pass  # 什么都不做

#### 2. **常见用法**

##### (1) **作为占位符**

当你写代码时，某些逻辑还未完成，可以使用 `pass` 作为占位符，确保程序不会因缺少[代码块](https://so.csdn.net/so/search?q=%E4%BB%A3%E7%A0%81%E5%9D%97&spm=1001.2101.3001.7020)而报错：

>  def my_function():  
>     pass  # 将来实现这个函数

##### (2) **空循环**

需要一个循环，但暂时不需要任何操作时：

>  for i [in range](5):  
>     pass  # 循环什么也不做

##### (3) **空类定义**

在定义一个类时，暂时还没有具体实现：

>  class MyClass:  
>     pass  # 占位，稍后[添加属性]和方法

##### (4) **异常处理占位**

在处理异常时，暂时不做任何处理：

>  try:  
>     x = 10 / 0  
> except ZeroDivisionError:  
>     pass  # 暂时忽略除以零的错误

#### 3. **为什么不用注释代替？**

- **语法规则**：在需要语句的地方必须有实际代码，而注释不会被解释器识别为语句。
- **代码可运行**：`pass` 确保程序不会因缺少代码块而出错。

---

#### 4. **示例：没有 `pass` 会报错**

下面的代码会报错，因为 `if` 语句块不能为空：

>  if True:  
>     # 什么都没有

错误信息：

>  IndentationError: expected an indented block

使用 `pass` 后，代码正常运行：

>  if True:  
>     pass

#### 5. **`pass` 与其他控制语句的区别**

- **`pass`**：什么都不做，仅作为占位符。
- **`continue`**：跳过当前循环的剩余部分，直接进入下一次循环。
- **`break`**：终止当前循环。
- **`return`**：结束函数并返回值。
